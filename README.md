# DMV AI Scout

A Claude plugin that finds new core AI/ML conferences, summits, meetups
and trainings in DC, Maryland and Virginia and emails you only the new ones.

## Requirements
- Claude with the Gmail connector connected

## Install (Claude app)
1. Download this repo: green **Code** button → **Download ZIP**
2. In Claude: Customize → Plugins → Add → Upload plugin → upload the zip
3. Ask Claude: "Run the DMV AI scout"

## Run it daily
Ask Claude: "Create a scheduled task that runs the DMV AI scout every day at 8 AM."
